# StudentPlanner
StudentPlanner is a Java-based productivity application that helps students organize assignments, study sessions, gym schedules, and personal activities in one place. The program tracks a user's daily schedule and can identify when they are falling behind on important tasks.

# MVP Scope
The first version of the project will include:

Creating and managing tasks
Assignment tracking
Study schedule tracking
Gym schedule tracking
Free-time planning
Daily dashboard
Progress tracking
Basic alerts when a user falls behind schedule

# Future Plans (Version 2.0+)
Phone notifications
Google Calendar integration
Automated schedule recommendations
Productivity analytics
Recurring schedules
Long-term goal tracking
